- 버전별 기능 설명은 실제 UI와 함께 갱신하고, 캡처에는 예시 데이터 여부와 대상 버전을 표시합니다.

- 폐기한 플랫폼이나 기능의 사용법은 현행 README에서 안내하지 않고 보관 문서로 구분합니다.
