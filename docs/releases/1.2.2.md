# AI Usage Viewer 1.2.2

Windows 개발판과 실사용 설치본의 실행 파일·계정 데이터·오류 로그를 분리합니다.

- `build-dev-widget.ps1`은 `artifacts/dev-build`에 개발판을 빌드하고, `run-dev-widget.cmd`는 별도의 `artifacts/dev-profile`만 사용합니다. 기존 `Release`와 실사용 설치본은 덮어쓰지 않습니다.
- `--data-dir`로 실행한 앱의 오류 로그와 이전 로그도 해당 프로필에 저장합니다. 개발·검증 로그가 실사용 폴더에 섞이지 않습니다.
- `run-widget.cmd`는 설치본만 실행합니다. 설치본이 없을 때 개발 빌드를 실사용 계정으로 대신 실행하지 않습니다.

실사용 계정·설정의 기본 위치는 `%LOCALAPPDATA%\AIUsageWidget`으로 유지합니다. Windows 패키지 환경에서 생성된 별도 프로필은 자동으로 병합하거나 인증을 변경하지 않습니다. 실사용은 Windows 시작 메뉴의 설치본으로 실행하고, 개발판에는 실제 계정을 연결하지 않는 것을 권장합니다.

Windows 업데이트는 앱의 **설정 → 앱 업데이트**에서 다운로드·재시작을 직접 선택합니다. macOS는 동일 소스 커밋에서 검증한 CPU별 번들을 제공합니다.
