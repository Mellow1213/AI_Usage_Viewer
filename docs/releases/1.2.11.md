위젯을 로고로 접어둔 동안 WebView2가 사용하는 RAM을 줄였습니다.

- 접기 애니메이션이 끝나고 5초가 지나면 저메모리 모드를 적용합니다. 카드를 펼치기 시작할 때 정상 모드로 복귀합니다.
- 저메모리 모드에서도 로고 애니메이션, 로고 찾기, 백그라운드 사용량 조회가 계속 동작합니다.
- 같은 Windows PC에서 예시 카드 두 개로 조건별 4회 비교한 결과, 로고 상태의 평균 전용 상주 RAM이 153.4 MiB에서 137.0 MiB로 약 10.7% 줄었습니다. 변경판에서 두 카드가 완전히 표시되기까지는 약 0.59~0.60초가 걸렸습니다. 절감량과 표시 시간은 환경에 따라 달라집니다.

Windows x64 정식 버전입니다. **설정 → 앱 업데이트 → 업데이트 확인 → 다운로드 및 업데이트 → 재시작하여 적용**에서 업데이트할 수 있습니다.
