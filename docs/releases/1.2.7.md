사용량 추이를 별도 옵션 화면으로 개편하고 Windows x64 전용 배포로 정리했습니다.

- 카드에 있던 비교 구간 총소비량과 작은 그래프를 **설정 → 사용량 추이**로 옮겼습니다. 상세·간략 카드에서는 기존 잔여량과 관측 사용량을 확인합니다.
- `30m · 1h · 3h · 6h · 12h · 1d` 기간을 바꾸면 현재 시각을 기준으로 저장된 기록을 즉시 계산합니다. 총소비량(%p), 실제 관측 시간, 시간·소비량 눈금이 있는 그래프를 함께 표시합니다.
- 마우스로 구간을 살펴보고 클릭으로 선택을 고정할 수 있습니다. 방향키·Home·End로 구간을 이동하고 선택을 해제할 수 있습니다.
- 미관측 시간은 빈 구간, 실제 관측된 소비량 0은 기준선으로 구분합니다. 일부만 관측된 기간은 합계도 관측된 부분의 값임을 안내합니다.
- 추이 화면을 열 때만 최근 시계열 데이터를 전달합니다. 서비스 조회 주기와 오늘 관측 사용량의 집계 설정은 유지합니다.
- Mac 빌드·실행 스크립트, Mac CI, Mac ZIP 배포·검증을 제거했습니다. 1.2.7부터 신규 배포 대상은 Windows x64입니다. 과거 Mac 소스와 이미 공개된 릴리스는 보관합니다.
- README를 설치·계정 연결·사용량 추이·업데이트·개인정보·문제 해결 중심으로 다시 정리하고 최신 예시 화면을 추가했습니다.

설치본에서는 **설정 → 앱 업데이트 → 업데이트 확인 → 다운로드 및 업데이트 → 재시작하여 적용** 순서로 사용자가 직접 업데이트합니다. 기존 계정·설정·관측 기록은 유지합니다.
