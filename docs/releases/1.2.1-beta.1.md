# AI Usage Viewer 1.2.1 Beta 1

- Windows와 macOS에서 한도가 초기화되면 해당 한도의 누적 소모량, 최근 소모량과 소모 구간 표시를 함께 0으로 초기화합니다.
- 초기화권·회사 측 초기화처럼 초기화 시각이 그대로여도 잔여량이 100%로 복구되면 새로 집계합니다. 초기화 시각을 지난 새 주기도 감지합니다.
- 설정한 집계 주기를 기다리지 않고 다음 새 사용량 수신 시 초기화를 반영합니다. 다른 한도·계정의 소모량은 유지하며, 이후 사용한 양만 다시 쌓습니다.
- 수치 보정·미세한 초기화 시각 변동, 오래된 사용량 수신과 재실행으로 소모량이 잘못 지워지거나 중복 집계되지 않도록 검증했습니다.

베타 테스트 버전입니다. Windows는 이 릴리스의 `Mellow.AIUsageViewer-win-Setup.exe`로 베타에 참여할 수 있습니다. 이후 베타 앱의 업데이트 확인은 사전 릴리스도 포함합니다. 기존 정식 설치본에는 베타가 자동 제공되지 않습니다.

Mac은 Apple Silicon용 `arm64`, Intel용 `x86_64` ZIP 중 하나를 받아 앱을 종료한 뒤 `AI Usage.app` 전체를 교체합니다. 계정·설정 데이터는 유지됩니다.
