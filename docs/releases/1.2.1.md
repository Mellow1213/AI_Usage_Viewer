# AI Usage Viewer 1.2.1

Windows·macOS의 소모량 초기화 개선을 정식 업데이트로 제공합니다.

- 초기화권·시간 만료·서비스 측 초기화로 한도가 복구되면 해당 한도의 누적 소모량, 최근 소모량과 막대의 소모 구간을 함께 0으로 초기화합니다.
- 초기화 시각이 그대로여도 잔여량이 100%로 돌아오면 새로 집계합니다. 다음 새 사용량 수신 시 집계 주기를 기다리지 않고 반영합니다.
- 초기화 이후 사용한 양만 다시 쌓으며 다른 한도·계정의 소모량은 유지합니다. 수치 보정, 오래된 수신값과 재실행에 대한 검증을 포함합니다.

Windows는 기존 정식 앱의 **설정 → 앱 업데이트 → 업데이트 확인 → 다운로드 및 업데이트 → 재시작하여 적용**으로 받을 수 있습니다. 이전 사전 릴리스 사용자도 이 정식 버전으로 업데이트할 수 있습니다. 계정·설정 데이터는 유지됩니다.

Mac은 Apple Silicon용 `arm64`, Intel용 `x86_64` ZIP 중 하나를 받아 앱을 종료한 뒤 `AI Usage.app` 전체를 교체합니다.
