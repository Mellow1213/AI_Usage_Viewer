설정 화면의 이동 단계와 뒤로 가기·닫기 동작을 일관되게 정리했습니다.

- **뒤로**는 실제로 거쳐 온 직전 화면으로 한 단계 이동합니다. 메인의 AI 추가·관측 측정 바로가기에서 연 화면은 메인으로 돌아갑니다.
- **×**나 상단 경로의 **사용량**을 누르면 설정 전체를 닫고 이전 상세·간략 카드로 돌아갑니다. 설정을 다시 열면 첫 화면에서 시작합니다.
- 상단에 현재 화면까지의 이동 경로를 표시하며, 이전 경로를 눌러 해당 화면으로 바로 돌아갈 수 있습니다.
- 계정 추가를 취소하면 진입했던 화면으로 돌아가고, 추가를 완료하면 계정 관리로 이동합니다. 뒤로 가기로 계정 선택창이 다시 열리는 동작을 방지했습니다.
- 사용량 그래프는 기존처럼 **설정 → 사용량 측정 → 그래프 보기**에서 필요할 때 열 수 있습니다.

Windows x64 정식 버전입니다. 기존 계정·설정·관측 기록을 유지하며, 앱에서 **설정 → 앱 업데이트 → 업데이트 확인 → 다운로드 및 업데이트 → 재시작하여 적용**으로 직접 업데이트할 수 있습니다.
