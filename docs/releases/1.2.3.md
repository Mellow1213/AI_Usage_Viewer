# AI Usage Viewer 1.2.3

- macOS에서 진행 중인 WebKit 비동기 작업과 유휴 화면 해제가 충돌하지 않도록 화면 수명을 관리합니다.
- 해제된 화면 접근과 화면 교체 전의 늦은 결과를 명시적인 오류로 처리합니다.
- Intel 및 Apple Silicon 화면 검사에 5초 유휴 시간을 넘는 작업과 해제·복원 회귀 검사를 추가합니다.
- 화면 검사 실패 시 앱 종료 신호·진행 단계·충돌 보고서를 보존해 결과 파일 누락과 구분합니다.

이 파일은 배포 후보의 변경 기록입니다. 정확한 소스 커밋에 대한 Desktop verification 통과와 공개 패키지 검증 후 배포합니다.
