접거나 다른 창 뒤에 가려진 위젯을 다시 찾을 수 있도록 **로고 찾기**를 추가했습니다.

- **Ctrl+Alt+L** 또는 Windows 트레이 아이콘의 우클릭 메뉴에서 **로고 찾기**를 실행합니다.
- 위젯이 현재 위치에서 앞으로 나오고, 로고 주변에 약 1.4초 동안 연두색 링이 표시됩니다. 키보드 입력은 사용 중인 앱에 남고, 강조가 끝나면 기존 상단 고정 설정이 다시 적용됩니다.
- 단축키가 이미 사용 중이면 트레이 메뉴에서 호출할 수 있습니다. 동작 줄이기 환경에서는 고정된 링을 표시합니다.

Windows x64 정식 버전입니다. **설정 → 앱 업데이트 → 업데이트 확인 → 다운로드 및 업데이트 → 재시작하여 적용**에서 업데이트할 수 있습니다.
