# AI Usage Viewer 1.2.4

- 기본 위젯을 유지하고 `설정 → 사용 기록`에 필요할 때 여는 분석 화면을 추가했습니다. 일별을 기본으로 시간별·주별 전환, 계정·한도 선택, 기간 이동을 지원합니다.
- 관측된 0, 일부만 관측한 구간, 미관측 구간을 구분합니다. 미관측은 빗금과 `—`로 표시하며 소비량 0으로 채우지 않습니다.
- 새로 수신한 기록을 기기에 최대 90일 보존합니다. 재실행·연결 오류·10분 초과 수신 공백·한도 초기화 전후는 이어 붙이지 않으며, 과거 기록은 초기화 후에도 남습니다.
- 기록은 수신한 한도 변화량(%p)이며 토큰 수나 전체 소비량이 아닙니다. 기존 기록의 소급 복원은 하지 않습니다. Windows와 macOS에서 같은 화면을 사용합니다.

계정 저장 위치, 삼각형 아이콘과 애니메이션, 기존 위젯과 사용자 버튼을 통한 업데이트 적용 방식은 유지됩니다.
