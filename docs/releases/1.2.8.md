사용량 그래프를 필요할 때만 여는 보조 분석 기능으로 정리했습니다.

- 그래프는 **설정 → 사용량 측정 → 그래프 보기**를 눌러 엽니다. 설정 첫 화면의 사용량 추이 바로가기를 제거했습니다.
- 사용량 측정 화면은 집계 주기를 중심으로 표시하고, 그래프 열기는 아래의 **추가 분석**에 배치했습니다. 비교 구간 선택은 그래프 화면에서 합니다.
- 그래프에서 뒤로 가면 사용량 측정 화면으로 돌아갑니다. 그래프를 벗어나면 최근 시계열 데이터 전달도 중단합니다.
- 메인 상세·간략 카드에는 그래프나 접힌 그래프 영역을 표시하지 않습니다. 기존 잔여량·초기화 시간·관측 사용량은 유지합니다.

Windows x64 정식 버전입니다. 기존 계정·설정·관측 기록을 유지하며, 앱에서 **설정 → 앱 업데이트 → 업데이트 확인 → 다운로드 및 업데이트 → 재시작하여 적용**으로 직접 업데이트할 수 있습니다.
